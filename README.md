# cloudvibe.de — Single-Page Landing Page Concept

Modern React + Vite + TypeScript single-page landing page redesign for **cloudvibe GmbH** (Goch, Germany).

## Highlights
- **Dark & Light Theme** in cloudvibe's brand palette (`#2eb329`, `#185098`, `#ff8c42`) with instant switching and persistence.
- **Orbital Hero & Animated Logo**: Animated SVG cloudvibe binary-cloud logo framed by concentric orbital rings and interactive service tiles.
- **Collapsible Studio Sidebar & Top Bar**: Quick section navigation with active scroll-spy, dropdown service menus, remote support modal, and consultation booking modal.
- **Authentic Content & Photos**: All 13 cloudvibe services (Telematikinfrastruktur, Healthcare, Managed Services, DATEV, SelectLine), interactive live architecture preview, real team and office photos from `cloudvibe.de`, anonymized healthcare references, and contact form.
- **Animated Aurora Footer**: Flowing gradient banner, interactive featured solutions strip, responsive 5-column sitemap, and kinetic binary signature.

## Local Development

